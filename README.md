# 保費融資計算器

給香港保險顧問使用的客戶演示工具。根據顧問提供的演示退保價值（PFCal），計算保費融資的首期、利息、預計淨收益與以首期計的平均每年回報，並可比較不同計劃、融資與自資，以及息率變化情景。

本網站**不是**任何保險公司或銀行的官方頁面，亦不是 10Life 的產品頁。計劃選擇器會顯示已確認的官方產品全名，代號（例如 GGG、ES、WIS3）只作輔助標示。演示退保價值與分紅實現率均僅供說明，並非保證。

## 如何在本機開啟

此為純靜態網站（HTML / CSS / JS），不必編譯。

**方法一：直接打開檔案**

用瀏覽器開啟 `index.html` 即可（網站已把計劃數據內嵌於 `js/app.bundle.js`，不依賴 `fetch`，因此 `file://` 亦可運作）。

**方法二：本機靜態伺服器（建議）**

在專案目錄執行：

```bash
python3 -m http.server 8080
```

然後在瀏覽器打開 <http://localhost:8080/>。看完後以 `Ctrl+C` 結束伺服器。

## 如何放到網上

任何靜態託管都可以，例如：

- **GitHub Pages**：把本資料夾推到 GitHub 倉庫，在 Settings → Pages 選擇該分支與根目錄（或 `/docs`，若你把檔案放在 docs）。
- Netlify、Cloudflare Pages、Vercel：直接指向本資料夾，無需 build command。若需要，build command 可填 `npm run bundle`，發布目錄為本資料夾本身。

更新 `data/plans.json` 或 10Life 公司比較數字後，請執行：

```bash
npm run bundle
```

這會由 `data/plans.json` 產生 `js/plans-data.js`，由 `scripts/generate-fulfillment-data.js` 產生精簡的 `js/fulfillment-data.js`（10Life 2025 報告年度公司平均，不會把來源專案裡約 1.9MB 的保監局擷取檔打包進網站），並產生瀏覽器用的 `js/app.bundle.js`。計算與資料測試：

```bash
npm test
# 或：node test/calc-test.js && node test/fulfillment-test.js
```

## 數字如何計算

所有計劃均為整付（一次過）保費。以保單貨幣計算，再按匯率換算港元。

- **折扣後保費** = 原保費 ×（1 − 折扣）
- **首日退保價值** = 原保費 × 首日退保比率
- **貸款額** = 首日退保價值 × 貸款成數（LTV）
- **首期投入** = 折扣後保費 − 貸款額
- **第 t 年演示退保價值** = 該年比率 × 原保費
- **年利息** = 貸款額 × 該年息率（單利，利息另行支付，不會滾入本金）
- **預計淨收益** = 退保價值 − 累計利息 − 貸款 − 首期  
  （等價於：退保價值 − 累計利息 − 折扣後保費）
- **總回報** = 預計淨收益 ÷ 首期
- **以首期計平均每年回報（AVR）** = 總回報 ÷ t  
  這是與 Excel 一致的**簡單平均**，不是複合年增長率（CAGR）。

預設融資息率（可在「假設與參數」修改）：

- 一般計劃：第 1–4 年 2.5%；第 5–10 年為 P − 1.8%（預設 3.7%）
- `fwd-wih-usd` 例外：第 1–4 年 2.5%；第 5–7 年為 P − 3%（預設 2.5%）；第 8–10 年 3.7%

**自資比較**：投入為整筆折扣後保費、沒有貸款與利息；淨收益 = 退保價值 − 折扣後保費。融資的回報率通常較高，是因為分母（首期）較小；絕對收益須扣除利息，不一定高於自資。貸款額同時顯示為「釋放資金」。

「釋放資金再投資」為選擇性示意（預設關閉），以貸款額 × 年率 × 年期作簡單累計，**不是**保單演示價值的一部分。關閉時，主要利潤數字與 PFCal 主欄一致。

## 折扣如何套用

若計劃有折扣級距表，會先把保費換算成美元，再對應級距。沒有級距的計劃（香港人壽 WP、永明 RF）使用工作表上的折扣。

**周大福人壽 PT 的特別說明：** Excel 工作表儲存格目前把折扣寫成 0%，但同一張表的級距為「低於 150 萬美元 5%／達到或超過 150 萬美元 6%」。本計算器**預設採用級距表**（示例保費 50 萬美元時為 5%），不會默默使用 0%。如需覆寫，可在「假設與參數」改為手動輸入。

## 匯率

預設 **1 美元 = 7.75 港元**，可在參數中修改。中文界面的較大金額會以「萬港元／萬美元」顯示（1 萬 = 10,000），並附上精確數字；英文界面使用一般貨幣格式。

## 年期比較（不會寫死第 7 對第 8 年）

每份計劃的演示路徑不同：有的在第 8 年跳升，有的在第 10 年較明顯，有的較平滑，有的在第 5 年仍為虧損。因此頁面不會一律比較第 7 與第 8 年。

預設會按**當前假設**自動選出 2 至 3 個參考年期：

1. **轉正**：預計淨收益首次由負轉正的年度（若第 1 年已為正數則不單獨做對比卡）。
2. **增值加快**：在第 5 至 10 年中，相對前一年淨收益跳升最明顯、且幅度有意義的年度；對比卡可同時展示加快前的一年。
3. 若路徑平滑、沒有明顯跳升：改以持有 5 年與 10 年作參考（若第 5 年仍虧損，則改用轉正年度對第 10 年）。
4. 若其後還有第二次明顯加快，或平均每年回報在跳升後仍明顯上升，可能再加一張較後年期的參考卡。

你也可以改為自選任何兩年；轉換計劃時，若未鎖定自選年期，會重新自動選取。虧損年份（例如香港人壽 WP 港元計劃第 5 年）會如實以紅色顯示，不會隱藏。

## 保險公司分紅實現率比較（10Life）

此節預設收合；點擊標題「保險公司分紅實現率比較（10Life）」才展開。多計劃比較下方的相關公司摘要條亦同樣預設隱藏，展開後才顯示數字。內容改以 [10Life 2026-11-13 文章](https://www.10life.com/zh-HK/blog/Comparing-Dividend-Fulfillment-Ratios-of-savings-insurance-across-Insurers) 的 **2025 報告年度** 公司級平均，按平均實現率由高至低排列（平均相同則再按「高於 70% 佔比」及數據點數量；相同平均顯示相同名次）。數字為有效數據點的簡單平均，並非按銷售額加權，也**不是**保監局產品級官方披露，更不是本計算器個別計劃的實現率。本網站不會把 10Life 的公司平均當成某一系列（例如不會把「富衛」平均當成 FWD Bermuda，或把「中銀人壽」平均當成薪火傳承環球）。

10Life 英文版同一 slug 目前仍是較舊的 2024 報告年度文章；本頁英文界面所載數字仍以繁中 2025 報告年度原文為準，並連到該繁中文章。

過往分紅實現率並不代表將來表現，亦不是投資回報率；由高至低只是方便閱讀的排序，不是公平的一對一排名。`data/fulfillment-ratios.json` 仍可留在來源專案作研究檔，但不會打包或從網站連結。
